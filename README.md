# Camunda Modeler Plugins

This repository contains a collection of plugins for the [Camunda Modeler](https://camunda.com/products/modeler/), designed to enhance BPMN modeling workflows.

## Plugins

### BPMN XML Sorter Plugin

A plugin that automatically sorts BPMN XML elements alphabetically on save, improving Git diff readability by ensuring consistent element ordering.

- **Location**: [`bpmn-sorter-plugin/`](bpmn-sorter-plugin/)
- **Details**: See [bpmn-sorter-plugin/README.md](bpmn-sorter-plugin/README.md) for installation, usage, and development instructions.
